Sum of two numbers

Given an array nums of integers and an integer target, return the indices of two different
elements whose sum equals target. Exactly one answer exists. The order of the two indices
does not matter.

Constraints:
2 <= nums.length <= 10^5
-10^9 <= nums[i] <= 10^9
-10^9 <= target <= 10^9

Example 1:
Input: nums = [2, 7, 11, 15], target = 9
Output: [0, 1]
